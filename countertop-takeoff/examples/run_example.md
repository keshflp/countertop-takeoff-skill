The generator draws at 1/4" = 1'-0" (18.0 pt/ft) and computes the known areas
from the very coordinates it draws, so "known" below is exact by construction.

## 1. Index the set

```console
$ uv run scripts/index_pdf.py examples/fixture.pdf
```

```text

| 1 | A-001 | UNIT SCHEDULE | YES | yes | 4 | 0 | A |
| 2 | A-101 | TYPE A FLOOR PLAN - 1 BEDROOM | - | yes | 2 | 3 | A |
| 3 | A-102 | TYPE B FLOOR PLAN - 2 BEDROOM | - | yes | 2 | 3 | B |

Unit-schedule candidates : [1]
Plan-sheet candidates    : [1, 2, 3]
Next: READ the full page text in the JSON to extract the unit schedule counts.
      (Never read quantities from rendered images. Text and vector data only.)
```

Page 1 is flagged as the unit schedule (multiplier table: Type A ×3, Type B ×2,
read from page TEXT in the JSON — never from an image). Pages 2–3 are the
per-type plan sheets.

## 2. Extract vector geometry for the plan sheets

```console
$ uv run scripts/extract_geometry.py examples/fixture.pdf --pages 2,3 --out build/fixture.geometry.json
```

```text
page 2: 23 segments, 32 words  (sheet A-101)
page 3: 21 segments, 32 words  (sheet A-102)

```

## 3. Measure with `examples/fixture.jobs.json`

vector data), the schedule counts read from A-001, and expected sanity ranges.
