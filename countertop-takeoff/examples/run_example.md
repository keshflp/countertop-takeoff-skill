# Verified example run — synthetic fixture (V2)

End-to-end run of the V2 pipeline on `examples/fixture.pdf`, generated by
`examples/make_fixture.py` (SYNTHETIC data — not a real project). Commands
run from the `countertop-takeoff/` skill folder. The generator is
byte-deterministic, so the example job spec's pinned source hash
(`c211e10b…`) matches the regenerated PDF exactly.

## 2. Extract geometry (IDs + rotation-aware)

```console
$ uv run scripts/extract_geometry.py examples/fixture.pdf --pages all --out build/fixture.geometry.json
```

```text
page 1: 8 segments, 93 words, class text_only  (sheet A-001), rot 0)
page 2: 23 segments, 32 words, class vector  (sheet A-101), rot 0)
page 3: 21 segments, 32 words, class vector  (sheet A-102), rot 0)
wrote build/fixture.geometry.json
```

Every segment/word carries a stable id. The job spec selects, per region,
the boundary segment ids (e.g. `A:kitchen` → ids 4–9 on page 2) and, per
(page, viewport), THREE calibration spans (e.g. `10'-0"` → word 29 /
segment 14; `2'-6"` → 30/17; `20'-0"` → 31/20). Code computes every length.

## 4. Audit pack + receipt

```console
$ uv run scripts/audit_pack.py build/results.json --pack build/audit_pack
$ uv run scripts/audit_pack.py build/results.json --record-receipt \
      --reviewer "fresh-agent: <session>" --verdict approved --notes "..."
```

Each region gets full-page + close-up overlays (translucent shell, seed
marker, calibration span highlights, the ACTUAL factor). The recorded
receipt flips `review_status` to `independent_audit_approved` in the results
JSON. Only then are the exports delivered.
